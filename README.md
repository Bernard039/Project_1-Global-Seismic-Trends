# Project_1-Global-Seismic-Trends
### Data-Driven Earthquake Insights
#### Project Overview
This project transforms raw earthquake data into actionable intelligence by pairing data engineering techniques with domain knowledge in seismology and disaster management.
##### Technical Stack & Key Skills
 * Data Extraction & Transformation: Cleansed and extracted unstructured text using Regular Expressions (Regex), processing raw dataset features via Python.
 * Data Warehousing: Designed SQL relational tables to structure, query, and efficiently manage historical seismic data.
 * Web Dashboarding: Built an interactive web app using Streamlit to visualize global earthquake trends, magnitudes, and geospatial distributions.
##### Industry Application
 * Geoscience & Seismology: Uncovering historical seismic patterns, fault behavior, and activity clusters.
 * Disaster Preparedness: Providing data-driven insights to support risk assessment and emergency response strategy.
